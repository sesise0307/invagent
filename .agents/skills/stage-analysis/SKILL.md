# Stage Analysis — 주가 성숙 4단계 판정

출처: DB증권 「Stage Analysis 마스터하기」(강현기, 2026-08-25). 스탠 와인스타인의 **주식 주기
4단계 이론**(가격·150일선)에 마크 미너비니의 **주가 성숙 4단계 이론**(영업이익 증가율)을 얹은
**통합 버전**을 구현한다. 이론 원문 요약은 `references/stage_theory.md`.

## 실행 순서

### 1단계 — 종목 확정

종목명이 모호하면 **먼저 되묻는다.** 스크립트가 exit 2와 함께 후보를 stderr로 뱉으면 그 목록을
사용자에게 그대로 보여주고 고르게 한다. 추측해서 진행하지 않는다.

### 2단계 — 스크립트 실행

```bash
uv run python .agents/skills/stage-analysis/scripts/stage_scan.py "<종목명 또는 6자리 티커>" \
  [--days 1100] [--project] [--no-fundamental] [--json] [--no-cache]
```

- 종료 코드: `0` 정상(부분 누락 포함) / `1` 시세 수집 실패 / `2` 종목명 후보 다수.
- 데이터 소스는 둘이다. **일봉은 StockEasy `info-tab` 정규장 일봉(쿠키 필요, 없거나 실패하면 네이버 `siseJson`으로 대체하고 출력에 꼬리표), 영업이익은 StockEasy
  `info-tab`(로그인 쿠키 필요)**. 수집 경로는 `market-data`.
- **우선주는 실적이 따로 없다.** 티커 끝자리가 `0`이 아니면 우선주이므로 영업이익 축만
  **본주 코드**(끝자리를 `0`으로 바꾼 값)로 받는다 (`datafeed.tickers.fundamentals_code`).
  가격 축(일봉·150일선·20주선·스윙)은 우선주 자기 시세를 그대로 쓴다 — 괴리율이 따로 움직이므로
  가격까지 본주로 대체하면 안 된다. 판별 근거는 `market-data` 스킬이 정본이다. 출처 줄에
  `우선주 실적은 본주 {이름}({티커})`가 붙으면 **그 꼬리표를 사용자에게 그대로 전달한다.**
- `STOCKEASY_COOKIE`가 없거나 만료되면 `[누락] info_tab —` 한 줄과 함께 **가격 전용 판정(와인스타인
  원본 버전)으로 강등**되고 판정은 계속된다. 이때 결과에 「가격 전용 판정」 꼬리표가 붙으므로
  **그 꼬리표를 사용자에게 그대로 전달한다.** 쿠키 갱신법은 `market-data` 스킬이 정본이다.
- ⛔ 쿠키 값을 대화·보고서·로그에 출력하지 않는다.

### 3단계 — 판정 해석

**단계 숫자는 스크립트가 확정한다.** 모델이 바꾸지 않는다. 뒤집으려면 스크립트가 볼 수 없는
사실(유상증자·합병·거래정지·액면분할·상장 초기 등)을 근거로 대고, **원 판정값을 함께 남긴다.**

읽는 순서:

1. `판정` 줄 — 단계와 확신도.
2. `근거` 줄 — 가격 3요소(위치·기울기·스윙) 점수, 경계 규칙 발동 여부, 영업이익 축 정합.
3. `직전 순환적 고점/저점` 줄 — 경계 규칙의 감시선. 다음 매매 트리거로 쓴다.
3-1. `20주선` 줄 — 「기술적 분석 규칙 1」이 요구하는 축이다. **150일선과 다른 선이므로 대신 읽지 않는다.**
   실제 주간 종가로 계산한다. 합성 날짜인 테스트 입력에서는 5개 일봉을 한 주로 묶는다. 예전 일봉 100일 근사와 혼동하지 않는다.
   방향 옆 변화율은 20주 이동평균의 **1주 변화율**이다. 150일선의 20거래일 변화율과 구분한다.
   이 줄이 `advice` 룰 체크의 「주봉 20주선: 방향 + 주가 위치」와 `analyze-stock` 10단계의 입력이다.
4. `거래량(보조)` — **보조 지표다.** 3·4단계에서 해석이 겹치고 일간 노이즈가 커 단독 근거로
   쓰지 않는다 (리포트 p.18).

### 4단계 — 룰 연결

`context/my_rules.md`를 읽고 단계별 대응을 사용자 룰 번호로 옮긴다.

| 단계 | 대응 | 룰 |
|---|---|---|
| 1단계 | 기본은 관망. 단기 판정 「고개 들기」면 밸류 게이트 통과 시 1차 분할 한정 (「바닥 다지기」는 경로 C 조건 충족 시 그 절반) | 「기본 원칙 8(풍림화산)」 대기 · 「매매규칙 4」 분할 매수 |
| 2단계 | 매수 대상 구간 (경로 A, 추세 확인 진입) | 「매매규칙 2」 — 주도주의 추세 확인 진입. 1·3·4단계의 '고개 드는 초반'은 「단기 바닥 전환 판정」이 정본 |
| 2단계 후반 | 추격 금지 | 「매매규칙 11」 수익 쿠션 · 「매매규칙 12」 장대양봉 매수 금지 |
| 3단계 | 신규 매수 금지 — 밸류 게이트 통과 시 1차 분할만 예외, 분산. 예외도 「고개 들기」 또는 경로 C일 때만 | 「매매규칙 11」 24~30% 쿠션 · 「매매규칙 5」 분할 매도 |
| 4단계 | 접근 신중. 「고개 들기」 + 밸류 게이트 통과 시에만 1차 분할 예외 (경로 C면 그 절반) | 「매매규칙 6」 -15% 1차 분할 → -20% 전량 · 「매매규칙 8」 물타기 금지 |
| 공통 | 주봉 20주선 교차 확인 | 「기술적 분석 규칙 1」 |

- 이 표는 **국면 대응만 준다. 진입 가부의 정본은 `analyze-stock` 10단계**의 진입 경로 판정이다.
  1·3·4단계의 「밸류 게이트」(하방 막힘 + 손익비 ≥ 3.0 + 증량 트리거 명시)도 거기가 정본이다.
- 1·3·4단계에서 **언제** 들어가느냐는 아래 「단기 바닥 전환 판정」(`turn_scan.py`)이 정한다.
  150일선은 가치·소외주 바닥에서 너무 늦다 — 4단계에 수개월 묶이거나 저점 +30~50% 뒤에야 2단계가 된다.
  4단계도 단기 판정이 「고개 들기」면 더는 '하락하는 와중'이 아니므로 밸류 게이트가 열린다
  (2026-09-12 사용자 확정). 「하락 중」·「바닥 다지기」·「초입 지남」이면 닫혀 있다.
- **약한 2단계**(가격 2단계 + 영업이익 증가율 하락)면 비중을 조절한다 — 전형적 2단계 종목보다
  낮게 싣는다 (리포트 p.21).
- **약한 4단계**(가격 4단계 + 증가율 상승)는 4단계 대응을 유지하되 1단계 전환 후보로 감시한다.
- 보유 중이면 진입가 대비 손익을 「매매규칙 6·7」 라인으로 환산해 함께 제시한다.

### 5단계 — 출력

스크립트 출력을 그대로 옮기지 말고 아래 형태로 정리한다. 수치는 스크립트 값을 쓴다.

```
📊 {종목명}({티커}) — {N단계 / 약한 N단계} · 확신도 {높음/중간/낮음}

가격: 150일선 {위/아래/오르내림} · 기울기 {상승/평탄/하락} · 스윙 {높아짐/낮아짐/혼조}
20주선: {가격}원 · 방향 {상승/평탄/하락} · 주가 {위/아래/오르내림}  (실제 주간 종가) · 「기술적 분석 규칙 1」
펀더: 영업이익 증가율 {최근 확정 분기} {YoY} → {다음 추정 분기} {YoY} = {상승/평탄/하락}
감시선: 직전 순환적 {고점/저점} {가격}원 — {돌파 시 / 이탈 시} {전환 단계}로 재판정

대응: {단계별 대응 1~2줄, 사용자 룰 번호 인용}
```

### 전망 (`--project`) — 언제 단계가 바뀔 수 있나

「2단계 진입은 언제쯤이냐」, 「이평선까지 얼마 남았냐」를 물으면 이 옵션을 붙인다.

이동평균은 새 종가가 들어오고 150일 전 종가가 빠지며 움직인다. **빠져나갈 값은 이미
확정돼 있으므로**, 주가를 한 값으로 고정하면 이평선의 미래 경로는 산술로 정해진다.
예측이 아니라 계산이다 — 주가 가정이 틀리면 결과도 틀린다는 점을 반드시 함께 말한다.

출력 네 가지:

1. **주가 횡보 시 접촉일** — 지금 가격에서 안 움직이면 며칠 뒤 이평선과 만나는가. 이미 같으면 0거래일이다.
2. **기울기 '평탄' 진입일** — 이평선 하락(또는 상승)세가 언제 멎는가.
3. **시점별 필요 주가** — 20·40·60·80·100거래일 뒤 이평선과 같아지는 고정 가격은 얼마인가.
   `days < 150`이면 닫힌 해가 있다: `p = (MA - S/150) / (1 - days/150)` (S = 그 사이 빠질 종가 합).
4. **이탈 예정 종가** — 앞으로 이평선에서 빠질 과거 종가의 구간 평균. 현재가보다 높은 값이
   빠지는 구간일수록 이평선이 저절로 내려와 **따라잡을 거리가 빨리 줄어든다.**

해석할 때 지킬 것:

- 접촉은 **단계 전환을 뜻하지 않는다.** 체류 비율·기울기·스윙·경계 규칙을 적용해 별도로 재판정한다.
- 교차 전에 밟아야 할 중간 관문(직전 순환적 저점 회복 → 최근 스윙 고점 돌파)을 함께 제시한다.
  이 순서를 건너뛴 진입은 1단계 매수 금지에 걸린다.
- 필요 주가가 +40%를 넘는 단기 시나리오는 현실성을 낮게 잡고, 그렇게 말한다.

## 판정 규칙 (통합 버전)

| 단계 | 가격 vs 150일선 | 150일선 기울기 | 스윙 | 영업이익 증가율 |
|---|---|---|---|---|
| 1 (기초/무시) | 오르내림, 박스권 | 하락 멈추고 보합 | 혼조 | 평탄 |
| 2 (상승/매집) | 위 | 상승 | 저점·고점 높아짐 | 상승 |
| 3 (정점/분산) | 오르내림, 박스권 | 평탄 | 혼조 | 평탄 |
| 4 (하락/투매) | 아래 | 하락 | 저점·고점 낮아짐 | 하락 |

**가격 3요소가 단계를 확정하고, 영업이익 증가율은 강·약 등급만 조정한다.**

- **주가 위치가 먼저다.** 리포트의 1·3단계는 「주가가 150일선을 **오르내리는**」 상태다(p.5·p.8).
  주가가 150일선 위에 체류하면 2단계, 아래에 체류하면 4단계 — 이평선 기울기나 스윙이 어긋나도
  1·3단계로 보내지 않는다. 어긋난 요소는 근거에 ⚠️로 남기고 확신도를 낮춘다.
  **어긋난 방향이 뜻을 가른다** — 위 + 평탄이면 상승세가 식은 **2단계 후반**,
  위 + 하락이면 바닥에서 갓 올라탄 **1단계 후반~2단계 초입**이다. 아래 + 평탄은 4단계 후반,
  아래 + 상승은 4단계 초입. 후반과 초입을 뒤바꿔 읽으면 매수·매도 방향이 반대가 된다.
- 오르내리는 구간이면 이평선 기울기 + 스윙으로 가른다 — 상승 + 높아짐 → 2단계 초입,
  하락 + 낮아짐 → 4단계 진입.
- 그래도 혼재하면 52주 밴드 위치로 가른다 — 하단 1/3이면 1단계, 상단 1/3이면 3단계,
  중단이면 최근 1년 방향으로 (위였으면 3단계, 아래였으면 1단계).
- **경계 규칙** (리포트 p.20~21): 3단계인데 종가가 **직전 순환적 고점**을 넘으면 재차 2단계.
  1단계인데 종가가 **직전 순환적 저점**을 밑돌면 재차 4단계.
- **약한 단계** (p.21): 2단계 + 증가율 하락 → 약한 2단계. 4단계 + 증가율 상승 → 약한 4단계.

### 경로 C — 고개 들기 전 선매집

「매매규칙 2」 단서 조항의 가격 조건이다. 출력의 `accumulation`이 판정한다 — `바닥 다지기` 상태이면서
① 1년 고점 대비 -20% 이상 무너진 뒤의 바닥 ② 바닥 이후 30거래일 이상 종가 신저가 없음
③ 바닥 이후 최고 종가가 바닥 +25% 이내 ④ 현재가 바닥 +10% 이내, 넷을 모두 채우면 `eligible`이다.
손절선 `stop`은 바닥 종가 -3%(종가 판정)다.

가격 조건만으로는 경로가 열리지 않는다. **최근 확정 분기 영업이익이 전년 동기보다 증가**
(`stage_scan` 출력의 `op_growth.latest.increased`, 적자 축소 포함)와 밸류 게이트를 함께 통과해야
`analyze-stock` 10단계가 1차 트랜치의 절반을 연다. 근거는 2026-09-25 백테스트(관심 종목 8개,
2015~2026, 진입일 기준 공시된 분기만 사용): 바닥 30일 기준 영업이익 YoY 증가 그룹은 승률 47%·손절 53%,
감소 그룹은 승률 19%·손절 81%였고, 이 그룹에서 선매집이 고개 들기 진입보다 250일 평균 +7%p 앞섰다.
YoY 증감폭 개선(감소 둔화)은 필터로 작동하지 않았다. 실적 감소 중인 턴어라운드는 경로 B로만 본다.

### 임계값과 그 근거

리포트는 "위/아래", "평탄", "저점·고점이 높아진다"를 말로만 규정하고 수치를 주지 않는다.
아래는 **이 스킬이 정한 운영 기준**이다 (`stage_scan.py` 상단 상수).

| 상수 | 값 | 근거 |
|---|---|---|
| `MA_DAYS` | 150 | 리포트 p.17~18 — 한국처럼 등락이 잦은 시장에선 200일선보다 150일선이 낫고, 120·60일선은 주가가 자주 닿아 3·4단계 오판을 부른다. 200일선은 참고 병기만 한다 |
| `SLOPE_WINDOW` / `SLOPE_FLAT_PCT` | 20일 / ±1.5% | 20거래일(약 1개월) 변화율이 ±1.5% 안이면 "평탄". 분기 실적 주기보다 짧게 잡아 국면 전환을 늦지 않게 잡는다 |
| `POSITION_WINDOW` / 임계 | 20일 / 80%·20% | 하루 이탈로 단계가 뒤집히지 않게 최근 20일 체류 비율로 본다. 그 사이는 "오르내린다"(1·3단계 특징) |
| `PIVOT_K` | 좌우 10일 | 스윙 고저점 프랙탈 반경. 최근 10봉은 확정되지 않아 판정에서 빠진다 — 경계 돌파를 종가로 따로 보는 이유 |
| `BOX_WINDOW` | 60일 | 박스권 상·하단 측정 구간 (약 3개월) |
| `CYCLE_WINDOW` | 250일 | 직전 순환적 고점·저점 탐색 구간 (약 1년) |
| `LONG_BULL_PCT` / `LONG_BULL_WINDOW` | +8% / 20일 | 「매매규칙 12」의 **장대 양봉** 정의(2026-09-05 사용자 확정)와 그것이 진입가를 구속하는 구간. 정의의 정본은 `context/my_rules.md`이고 테스트가 원문과 대조한다 |
| `MA_20WEEK` | 20주 | 「기술적 분석 규칙 1」의 실제 주간 종가 20주 평균 |

임계값을 바꾸면 **이 표와 스크립트 상수를 함께 고친다.** 조정 근거를 여기에 남긴다.

동일값 처리(2026-09-08 오류 정정): 종가가 이평선과 같으면 위·아래 어느 쪽에도 세지 않되,
전체 표본에는 포함한다. 위 체류율 80% 이상이면 「위」, 아래 체류율 80% 이상이면 「아래」,
나머지는 「오르내림」이다. 반환하는 비율은 항상 위 체류율이다. 스윙은 고점과 저점이 모두
엄격히 높거나 낮을 때만 방향을 부여하고, 동일값이 섞이면 「혼조」로 남긴다.

종가 기준(2026-09-14 오류 정정): 스윙 고저점·직전 순환적 고점/저점·박스권·52주 밴드는 모두
**종가**로 잡는다. 예전에는 장중 고가·저가로 잡아, 경계 규칙이 종가를 장중 꼬리와 비교했고
`analyze-stock`이 종가 기준 추세 이탈선으로 쓰는 순환적 저점이 장중 저가였다 (GS피앤엘
2026-07-31: 장중 32,250원 · 종가 35,250원). `turn_scan.py`와 같은 기준이다.

### 영업이익 증가율 계산

리포트 p.23의 업종 판정과 같은 방식이다. **최근 확정 분기의 YoY 증가율**과 **다음 추정(컨센) 분기의
YoY 증가율**을 비교해 낮아지면 「하락」, 높아지면 「상승」.

- 동일 증가율은 「평탄」이며 약한 단계로 낮추지 않는다. 부동소수점 계산 오차만
  절대 차이 `1e-12`%p 이내에서 동일값으로 취급한다.
- 다음 분기는 달력상 바로 다음 분기다(4분기 다음은 다음 해 1분기). 추정치가 없으면
  더 먼 분기로 대체하지 않고 가격 전용 판정으로 남긴다.
- `available`은 두 분기의 증가율 비교 가능 여부다. 확정치만 있거나 비교가 불가능하면
  확신도를 「높음」으로 올리지 않는다. 「높음」은 가격 3요소와 실적 방향이 모두 정합할 때만
  부여하며, 실적 증가율이 평탄한 경우도 제외한다.

- 어닝 서프라이즈는 쓰지 않는다. 증가율과 엇갈릴 때 결론이 흔들려 현실과 멀어진다 (리포트 p.18).
- 전년 동기 영업이익이 0 이하면 증가율을 계산하지 않고 「판정 불가」로 남긴다 —
  적자 기저의 증가율은 부호가 뒤집혀 의미가 없다.

## 단기 바닥 전환 판정 (`turn_scan.py`)

「매매규칙 2」의 "바닥을 다진 후 고개를 들기 시작하는 초반"은 **이 판정기가 정본**이다. 스테이지는
150일선·250일 순환 고저점이라 주도주 국면엔 맞지만, 가치·소외주 바닥에서는 2단계 확인이 저점
+30~50% 뒤에 오거나 4단계에 수개월 묶인다. 이 스크립트는 일봉 20~60일 창으로 바닥과 전환을 본다.
근거 기법(와이코프 매집 · Sperandeo 1-2-3 · 앵커드 VWAP)과 출처는 `references/turn_theory.md`.

```bash
uv run python .agents/skills/stage-analysis/scripts/turn_scan.py "<종목명 또는 6자리 티커>" \
  [--days 400] [--json] [--no-cache]
```

- 종료 코드: `0` 정상 / `1` 시세 수집 실패·일봉 부족(130봉 미만) / `2` 종목명 후보 다수.
- 일봉만 쓴다 — StockEasy `info-tab` 정규장 일봉(쿠키 필요, 없거나 실패하면 네이버 `siseJson`으로 대체하고 출력에 꼬리표). 쿠키가 없어도 판정은 돈다. 수집 경로는 `market-data`.
- **상태는 스크립트가 확정한다.** 모델이 차트를 눈대중해 바꾸지 않는다.

### 상태

| 상태 (`state`) | 조건 (전부 종가) | 대응 |
|---|---|---|
| 하락 중 (`falling`) | 최근 15거래일 안에 바닥 저점을 새로 썼다 (Spring 제외) | 매수 금지 — 「매매규칙 2」 |
| 바닥 다지기 (`basing`) | 바닥 저점 이후 15거래일+ 신저가 없음, 고개 들기 조건 일부 미충족 | 관망. 돌파선 감시 |
| 고개 들기 (`turning`) | ① 저점 높임 ② 돌파선 종가 돌파 ③ 20일선 위 ④ 20일선 상승 ⑤ 앵커드 VWAP 위 — 전부 | 「매매규칙 2」의 초입. 밸류 게이트 통과 시 1차 |
| 초입 지남 (`extended`) | 돌파선이 있으면 돌파선 대비 +10% 초과 · 없으면(저점 높임 전 V자 반등) 저점 대비 +35% 초과 | 추격 금지 — 돌파선 +10% 이내로 눌리면 재판정 |

판정 순서는 하락 중 → 초입 지남 → 고개 들기 → 바닥 다지기다.

- **저점 높임이 확정돼 돌파선이 정해지면** 초입은 **돌파선 기준으로만** 잰다 — 돌파선 아래면 저점에서
  얼마나 올랐든 바닥 다지기(돌파 대기), 돌파 후 +10% 이내면 고개 들기, 그 위면 초입 지남
  (2026-09-12 사용자 확정). 저점 대비 상승률은 저점 높임이 아직 없는 V자 반등에만 쓴다.
  V자 반등은 저점 높임부터 이미 저점 +35%를 넘어서, 저점 기준을 계속 쓰면 초입 창이 처음부터 없거나
  (산일전기) 돌파 전엔 「초입 지남」, 돌파하면 「고개 들기」로 뜻이 뒤집힌다 (큐리옥스·이수페타시스).

- **바닥 저점** = 최근 120거래일 최저 종가. 단 그 구간의 최고 종가 이후 -20% 이상 무너졌으면
  **그 하락의 최저 종가**다 — 랠리 뒤 급락한 종목을 랠리 전 저점으로 재면 고점 대비 -40%인데도
  「초입 지남」이 나온다 (2026-09-12 SK하이닉스 실데이터). -20%에 못 미치는 눌림은 새 바닥이 아니다.
- **저점 높임** = 바닥 이후 확정된 마지막 단기 스윙 저점
  (좌우 5봉)이 바닥보다 높을 때. **돌파선** = 바닥과 저점 높임 사이 최고 종가 — 1-2-3의 2번 점이다.
- **Spring** (와이코프): 최근 15일 안의 신저가가 그 전 바닥을 3% 이내로만 깼고 종가가 그 바닥 위로
  돌아왔으면 이탈이 아니다. 바닥은 그 전 바닥으로 두고 **무효화선만 Spring 저점으로** 내린다.
  Spring 뒤에는 새 저점 높임이 확정돼야 고개 들기가 된다.
- **앵커드 VWAP** = 바닥 저점 봉부터의 거래량 가중 평균가. 종가가 위면 바닥 이후 산 사람들이 평균적으로
  이익이다 — 반등마다 쏟아지던 매물이 소화됐다는 뜻이다.

### 확신도 — 보조 증거 넷

돌파일 거래량(직전 50일 평균의 1.5배 이상) · 바닥 이후 상승일/하락일 거래량비(1.0 이상) · RSI(14)
강세 다이버전스(가격은 저점을 낮췄는데 RSI는 저점을 높였다) · Spring. **상태를 바꾸지 않고 확신도만
매긴다** — 2개 이상 높음 / 1개 중간 / 0개 낮음. 판정할 수 없는 항목은 `?`로 남기고 통과로도 탈락으로도
세지 않는다. RSI 다이버전스는 단독 승률이 40~45%에 그친다는 백테스트가 있어 게이트로 쓰지 않는다.

### 감시선과 분할 사다리

출력의 감시선이 「매매규칙 4(분할 매수)」 사전 계획의 증량 트리거다 (2026-09-12 사용자 확정, 1/3씩 3단).

| tranche | 여는 조건 |
|---|---|
| 1차 (목표 비중 ÷ 3) | 고개 들기 + 밸류 게이트 (`analyze-stock` 10단계) |
| 2차 | 눌림에서 저점 높임 가격 위 종가 유지 + 60일선 상향 전환 (20거래일 변화율 > 0) |
| 3차 | `stage_scan` 2단계 판정 또는 20주선 상승 전환 |

- 무효화선(바닥 저점, Spring이 있었으면 Spring 저점) 종가 이탈 → 하락 중 재판정. 경로 B 1차의
  추세 이탈선 후보다.
- 고개 들기 조건은 매일 다시 본다. 돌파 뒤 종가가 돌파선·20일선·앵커드 VWAP 아래로 되돌아오면
  (되돌림, throwback) 그날부터 바닥 다지기로 판정된다. 저점 높임 가격까지 종가로 깨지면 구조가
  훼손된 것이다. 되돌림의 저점이 새 저점 높임으로 확정되면 돌파선도 그 사이 최고 종가로 올라간다.

### 한계

- **V자 반등은 저점 높임이 확정되기 전까지 바닥 다지기로 남는다** (+35%를 넘으면 초입 지남).
  의도된 보수성이다 — 「매매규칙 12」 장대 양봉 추격 금지와 같은 방향이다.
- 최근 5봉은 스윙이 확정되지 않는다. 오늘 막 생긴 저점은 일주일 뒤에야 저점 높임으로 잡힌다.
- 모든 수준을 종가로 잡는다. 장중 저점으로 그은 차트의 지지선과 몇 % 다를 수 있다.
- 이 판정은 **타이밍**만 답한다. 싸냐·하방이 막혔냐는 `analyze-stock` 9단계 밸류가 답한다.

## 보조 도구 — 미너비니 추세 템플릿 점수

**`scripts/technical_score.py`** — 단계 판정과 별개로, 미너비니 추세 템플릿 8개 항목을 채점한다.
단계는 "지금 어느 국면인가"를, 이 점수는 "그 국면 안에서 얼마나 정석에 가까운가"를 답한다.

```bash
uv run python .agents/skills/stage-analysis/scripts/technical_score.py <일봉 JSON>
```

- 일봉 200개 미만이면 채점하지 않는다.
- `relative_strength`는 항상, `ma200_rising`은 봉이 400개 미만이면 `None`으로 남는다.
  **모르는 항목은 `?`로 표기하고 분모에서 빼지 않는다** — `advice` 스킬의 표기 규칙과 같다.
  8점 만점이 아니라 `passed/known`으로 읽는다.

## 하지 않는 것

- 지수·업종 판정은 이 스킬 범위 밖이다. 개별 종목만 본다.
- 목표주가·기대수익 산정은 하지 않는다 → `analyze-stock` 9단계.
- 보고서 파일을 만들지 않는다. 판정은 대화로 답하고, 보고서에 남길 때는 `analyze-stock`이
  §5 「📈 추세」에 스테이지 줄을 넣는다.

## 한계

- 150일선도 국면 판단에 완벽하지 않다 (리포트 p.18). 오판 가능성이 줄 뿐이다.
- 단계는 **사후에 바뀐다.** 2→3→2, 4→1→4 되돌림이 정상이다 (도표 13~16). 경계선을 감시선으로
  같이 제시하라.
- 상장 1년 미만·거래정지·액면분할 직후 종목은 150일선과 순환 고저점이 왜곡된다. 스크립트가
  일봉 부족으로 exit 1을 내면 그대로 알리고 판정하지 않는다.
- 거래량은 보조 지표다. 단독으로 단계를 뒤집지 않는다.

## 스킬 경계

- **단계만** 묻는다 → 이 스킬.
- "바닥 다졌어?", "고개 들었어?", "지금 초입이야?" → 이 스킬의 `turn_scan.py`. 스테이지와 함께 보여 준다.
- 종목을 끝까지 파고 보고서까지 남긴다 → `analyze-stock` (그 안에서 이 스크립트를 호출한다).
- 대가 관점 종합 조언·룰 충돌 정리 → `advice`.
