# 매크로 관점 참조

## 스탠리 드루켄밀러 (Stanley Druckenmiller)

### 핵심 철학
- "수익이 나는 방향에서는 크게, 잃는 방향에서는 작게 베팅하라."
- 유동성(Liquidity)이 모든 자산 가격을 결정한다 — 연준이 돈을 풀면 올라가고, 조이면 내려간다
- 우량한 기업도 잘못된 거시 환경에서는 살아남기 어렵다
- 틀렸다는 신호가 오면 즉각 포지션을 청산하라

### 드루켄밀러의 투자 프레임워크

**1단계: 유동성 환경 점검**
- 연준(Fed)이 금리를 올리는 중인가, 내리는 중인가?
- M2(광의통화) 성장률은 증가하는가, 감소하는가?
- 장단기 금리차(수익률 곡선): 역전 여부 확인
- 신용 스프레드(하이일드-국채 차이): 확대 = 리스크 오프

**2단계: 경기 사이클 위치 확인**
- ISM 제조업지수, 실업률, 소비자 신뢰지수
- 기업 이익 사이클의 위치 (상승 초입 vs. 고점 근처)
- 재정 정책: 정부 지출 확대 vs. 긴축

**3단계: 자금 흐름 방향**
- 달러 강세 vs. 약세 → 신흥국 자산에 반대 영향
- 원자재 수퍼사이클 여부 (에너지, 금속)
- 글로벌 자금이 미국으로 향하는가, 유럽·아시아로 향하는가?

### 드루켄밀러의 매매 원칙
- **크게 베팅하라**: 확신이 있을 때 분산하지 말고 집중하라
- **선물·외환 활용**: 방향성에 베팅할 때 레버리지 사용 가능
- **손절은 빠르게**: 거시 환경이 바뀌면 미련 없이 청산
- "나는 항상 거시 환경이 바뀌었을 때 틀렸음을 인정하는 법을 배웠다."

## 조지 소로스 (George Soros)

### 핵심 철학: 반사성 이론 (Theory of Reflexivity)
시장은 '객관적 현실'을 반영하지 않는다. 시장 참여자들의 **인식**이 현실을 바꾸고, 바뀐 현실이 다시 인식을 바꾸는 **피드백 루프**가 존재한다.

**상승 버블 피드백 루프:**
낙관적 기대 → 주가 상승 → 실적 개선 → 더 낙관적 기대 → ... (언젠가 붕괴)

**하락 악순환 피드백 루프:**
비관적 기대 → 주가 하락 → 신용 경색 → 실적 악화 → 더 비관 → ... (언젠가 반전)

### 소로스의 투자 접근법
1. **내러티브 파악**: 시장이 현재 어떤 스토리를 믿고 있는가?
2. **피드백 고리 확인**: 그 스토리가 자기 강화적인가?
3. **전환점 탐색**: 언제 내러티브가 깨지는가?
4. **큰 베팅**: 전환점이 확인되면 대규모로 역방향 또는 순방향 포지션

### 소로스가 즐기는 상황
- 정책 당국의 잘못된 고집 (1992년 영국 파운드 사례)
- 버블이 절정에 달했을 때 붕괴를 기다리는 포지션
- 환율 또는 금리의 구조적 불균형

### 소로스의 경고
- "시장은 오랫동안 비이성적으로 움직일 수 있다." — 너무 일찍 역방향 포지션을 잡으면 파산
- 반사성은 단기 예측을 불가능하게 만든다. 방향은 알아도 타이밍은 모른다
- 확신이 높을수록 더 큰 리스크가 있음을 경계하라 (오만의 역설)

## 매크로 환경 체크리스트 (실전 적용)

### 글로벌 (드루켄밀러 1~3단계)

```
□ 연준 스탠스: 금리 인상 / 동결 / 인하 사이클?
□ 인플레이션: 상승 중 / 하강 중 / 안정?
□ 달러 인덱스(DXY): 강세 / 약세 추세?
□ 미 10년물 국채금리: 상승 / 하락 / 횡보?
□ 하이일드 스프레드: 좁음(위험선호) / 넓음(위험회피)?
□ VIX(공포지수): 낮음(15 이하) / 보통 / 높음(30 이상)?
□ 원유/금 가격: 인플레이션 압력 신호?
```

### 🇰🇷 한국 증시 (필수 — 미국 지표만으로 한국 종목을 판단하지 마라)

한국은 소규모 개방경제 + 외국인 수급 의존도가 높은 시장이다.
같은 글로벌 환경에서도 **환율과 수급이 방향을 뒤집는다.**

```
□ 원달러 환율: 상승(원화 약세) / 하락(원화 강세) / 방향 전환?
   → 원화 약세 = 외국인 매도 압력 + 수출주 환산 실적 개선 (효과가 반대로 작용, 종목별로 갈림)
   → 1,400원대 이상은 외국인 이탈 경계 구간
□ 외국인 수급: KOSPI·KOSDAQ 각각 순매수 / 순매도, 연속 며칠?
   → 한국 시장 방향의 1차 결정 변수
□ 기관 수급: 연기금 방향, 금융투자(프로그램) 방향
□ 개인 수급: 개인이 홀로 순매수 중이면 하락 방어 실패 신호가 잦다
□ VKOSPI: 낮음(20 이하) / 보통 / 높음(30 이상) / 급등(패닉)
   → VIX 대신 한국 공포지수. 사용자 브리핑의 표준 지표
□ 신용잔고 · 반대매매: 잔고 고점 대비 수준, 반대매매 발생 여부
   → 반대매매 클라이맥스는 「레버리지 규칙 2」의 조건부 진입 근거
□ 한국 10년물 국채금리 · 한미 금리차: 역전 폭 확대 = 자본 유출 압력
□ 수출 지표: 월별 수출 증감률, 반도체 수출액, 일평균 수출
   → 한국 기업이익 사이클의 선행 지표
□ 중국 변수: 위안화, 중국 PMI, 대중 수출 비중 큰 섹터 영향
□ KOSPI / KOSDAQ 디커플링 여부: 어느 쪽이 주도하나
```

### 사용자 룰과의 접점

- **「레버리지 규칙 3(변동성 레버리지 청산)」**: 지수 ±5% 이상 변동일이 최근 10거래일 내 3일 이상이면
  레버리지 전량 정리 + 신규 진입 금지. 매크로 조언 시 **이 카운트를 먼저 확인**한다.
  (상승 방향 일관 변동은 예외)
- **「기본 원칙 13(계좌 MDD 관리)」**: 지수 급락 국면이면 계좌 MDD -10% / -15% 발동 여부를 함께 본다.
- **「매매규칙 6」 시장 급락 예외**: 예외를 적용하려면 **지수 낙폭 수치를 근거로 대야 한다.**
  "시장이 안 좋아서"는 근거가 아니다.
- **「레버리지 규칙 2」**: 패닉 셀에서는 반대매매 클라이맥스 또는 추세 회복 확인 후 분할 접근.
  단순 낙폭·하루짜리 반등은 진입 근거가 아니다.
