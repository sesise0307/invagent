# 투자 조언 스킬 (Advice)

이 스킬은 사용자의 투자 고민에 대해 세계 최고의 투자 대가들의 철학과 방법론을 빌려 조언을 제공한다.
단순한 인용이 아닌, 대가들이 실제로 해당 상황을 봤다면 어떻게 생각했을지를 그들의 언어와 논리로 재현하는 것이 목표다.

이 스킬은 **저장소 내 투자 판단 방법론의 정본**이다. `analyze-stock`(10단계), `summarize-telegram`(4단계),
`monthly-investment-review`(3단계)가 이 파일과 `references/`를 참조한다. 여기서 규정을 바꾸면 세 곳 모두에 적용된다.

---

## 스킬 경계 (analyze-stock 와의 분리)

| 요청 | 담당 |
|---|---|
| 종목명 + "분석해줘 / 파봐 / 리포트 읽고 판단해줘 / 밸류에이션 봐줘" | **analyze-stock** (리포트·DART·컨센 수집 + 보고서 저장) |
| 종목명 + "지금 사도 돼?" 인데 깊은 분석 요청 | **analyze-stock** |
| 특정 관점만 요청 ("버핏이면 / 차트상 / 매크로") | **advice** |
| 격언·명언 요청 | **advice** |
| 포트폴리오·시장 일반론, 룰 판정, 포지션 사이징 | **advice** |
| 이미 수집된 데이터(브리핑·보고서·포트 스냅샷)에 관점만 얹기 | **advice** |

애매하면 **analyze-stock 을 먼저 제안**하라. advice 는 데이터를 스스로 모으지 않는다 (아래 「데이터 조달」 참조).

---

## 시작 전 (필수 2가지)

### 1. 나만의 규칙 읽기

저장소 루트 기준 `context/my_rules.md`. **매수/매도/보유/손절/비중 등 의사 결정 조언 전에 반드시 읽어라.**
조언이 규칙과 충돌하면 규칙을 먼저 말한다.

**룰 인용 표기는 아래 형식으로 고정한다** (저장소 전체 공통):

```
「기본 원칙 N」 · 「매매규칙 N」 · 「레버리지 규칙 N」 · 「기술적 분석 규칙 N」
```

제목을 덧붙일 때는 괄호로: 「레버리지 규칙 3(변동성 레버리지 청산)」, 「기본 원칙 4(2%룰)」.
`my_rules.md`는 4개 절(기본/매매/레버리지/기술적)이 **각각 1번부터** 매겨져 있다.
절 이름 없이 「룰 6」 이라고 쓰면 기본 6·매매 6 중 무엇인지 알 수 없다. **절 이름을 반드시 붙여라.**

### 2. 데이터 조달

**숫자 없이 스테이지·거래량·RS·멀티플을 말하지 마라.** 사용자가 수치를 주지 않았고
대화 맥락(브리핑·보고서·포트 스냅샷)에도 없으면, 아래에서 가져온 뒤 조언하라.

| 필요한 것 | 출처 |
|---|---|
| 시세·멀티플·컨센서스·목표주가 이력·뉴스 | `.agents/skills/analyze-stock/scripts/fetch_stock_info.py <종목명\|티커>` (`STOCKEASY_COOKIE` 필요) |
| 과거 브리핑에서 이 종목이 언급된 이력 | `.agents/skills/analyze-stock/scripts/find_mentions.py <종목명>` → `path:line` 반환, 원본에서 읽는다 |
| 기존 종목 보고서 | `.agents/skills/analyze-stock/scripts/find_prior_report.py <종목명>` |
| 재무·공시·지분·배당 | `opendart` 스킬 |
| 보유 수량·평단·비중 | `output/portfolio/<yyyy-mm-dd>.md` (최신) |

조달이 실패하면 **실패했다고 밝히고**, 그 관점은 「데이터 없음 — 판단 보류」로 남긴다.
추정치로 채우지 마라. 데이터가 없는 관점을 억지로 쓰느니 비워 두는 편이 낫다.

## 작동 방식

사용자의 요청 유형을 먼저 파악하라:

1. **특정 관점 요청**: "버핏 관점에서 봐줘" → 해당 관점 + §5 룰 체크 + §6 종합
2. **종합 조언 요청**: "이 종목 어떻게 봐?" → 네 관점 + 격언 + §5 + §6 전부
3. **격언/명언 요청**: "투자 격언 알려줘" → 상황에 맞는 격언만 (§5·§6 생략 가능)
4. **시장 상황 진단**: "지금 매크로는?" → 매크로 + 2차적 사고 위주, §5는 계좌 레벨 룰만

**요청이 모호하면 묻지 말고 2번(종합 조언)으로 처리한다.** 관점을 좁히고 싶으면 사용자가 말한다.
단, **종목이 특정되지 않아 조언 자체가 불가능한 경우에만** 어떤 종목/이슈인지 되묻는다.

## 관점별 조언 방법

### 🏛️ 1. 가치투자 관점 (Value Investing)

**핵심 대가**: 워렌 버핏(Warren Buffett), 찰리 멍거(Charlie Munger), 피터 린치(Peter Lynch)

상세 방법론은 `references/value_investing.md` 를 참조하라.

이 관점에서 조언할 때 반드시 포함할 요소:
- 사업의 본질적 가치와 현재 가격 비교 (안전마진)
- 경영진의 자본 배분 능력과 정직성
- 경쟁 우위(해자)의 지속 가능성
- "10년 보유한다면?" 프레임으로 판단

**출력 형식:**
```
🏛️ 가치투자 관점 (버핏 / 멍거 / 린치)

[핵심 판단: 한 문장]

버핏이라면: [구체적 사고 방식]
멍거라면: [역발상 또는 심리 관점]
린치라면: [성장+가치 혼합 관점, 일반 투자자 눈높이]

주목할 지표: [PER, PBR, ROE, 부채비율 등 — 실제 수치 있을 때만]
```

---

### 📈 2. 차트·추세 추종 관점 (Technical / Trend Following)

**핵심 대가**: 마크 미너비니(Mark Minervini), 윌리엄 오닐(William O'Neil)

상세 방법론은 `references/trend_following.md` 를 참조하라.

이 관점에서 조언할 때 반드시 포함할 요소:
- 주가가 현재 어떤 스테이지에 있는지 (Stage 1~4 분류)
- **미너비니 트렌드 템플릿 8조건 채점** (`N/8`) — 항목별 충족 여부를 수치로
- **오닐 CAN SLIM 7항목 채점** (`N/7`)
- 거래량이 주가 움직임을 지지하는지 여부
- 베이스 패턴(컵핸들, VCP 등) 형성 여부
- 명확한 손절 기준과 진입 조건

채점은 반드시 `N/8`, `N/7` 형태로 남긴다. "대체로 충족" 같은 서술로 대체하지 마라.
데이터가 없어 채점할 수 없는 항목은 `?`로 표기하고 분모에서 빼지 않는다.

**출력 형식:**
```
📈 차트·추세 관점 (미너비니 / 오닐)

[현재 주가 스테이지 판단]

미너비니 트렌드 템플릿: N/8 — [미충족 항목만 나열]
오닐 CAN SLIM: N/7 — [미충족 항목만 나열]

진입 조건: [구체적 조건 — 단일 가격]
손절 기준: [명확한 선 — 단일 가격. 사용자 룰과 충돌하면 §5에서 정리]
```

---

### 🌍 3. 매크로 관점 (Macro)

**핵심 대가**: 스탠리 드루켄밀러(Stanley Druckenmiller), 조지 소로스(George Soros)

상세 방법론은 `references/macro.md` 를 참조하라. **한국 증시 항목(수급·환율·VKOSPI·신용잔고)을
반드시 함께 본다** — 미국 지표만으로 한국 종목을 판단하지 마라.

이 관점에서 조언할 때 반드시 포함할 요소:
- 현재 금리·유동성 환경과 종목/섹터의 관계
- 글로벌 자금 흐름이 어디로 향하는지
- 한국 특유 변수: 외국인·기관 수급, 원달러, VKOSPI
- 정책 사이클(연준, 재정) 상의 위치
- "한 가지 큰 베팅"이 있다면 무엇인지

**출력 형식:**
```
🌍 매크로 관점 (드루켄밀러 / 소로스)

[현재 거시 환경 한 줄 요약]

드루켄밀러라면: [유동성·금리 관점의 판단]
소로스 반사성 이론: [시장 내러티브와 현실의 피드백 루프]
한국 수급: [외국인·기관 방향, 원달러, VKOSPI 수준]

핵심 리스크: [매크로 관점의 주요 위험 요인]
```

### 🧭 4. 2차적 사고·사이클 관점 (Second-Level Thinking)

**핵심 대가**: 하워드 막스(Howard Marks), 세스 클라만(Seth Klarman)

상세 방법론은 `references/second_level_thinking.md` 를 참조하라.

사용자 「기본 원칙 12(2차적 사고)」·「기본 원칙 6(오늘이 원금)」의 방법론적 뿌리다.
**컨센서스가 이미 가격에 반영됐는지**를 다루는 유일한 관점이므로 직접 조언 시 생략하지 마라.

**3관점 고정 템플릿에서 호출된 경우** (`summarize-telegram` 브리핑, `analyze-stock` 보고서 §9):
별도 블록을 만들지 말고 **가치 관점의 "이미 가격에 반영됐나" 판단과 매크로 관점의 사이클 위치 판정에
녹여 쓴다.** 템플릿의 섹션 구성을 임의로 늘리지 마라.

이 관점에서 조언할 때 반드시 포함할 요소:
- 1차적 사고(시장 컨센서스)가 무엇인지 명시 → 그 너머의 2차적 질문
- 시장 사이클 진자의 현재 위치 (공포 ↔ 탐욕)
- 리스크 = 변동성이 아니라 **영구적 자본 손실** 관점의 하방 점검
- 지금 가격이 "좋은 자산"이 아니라 "좋은 거래"인지

**출력 형식:**
```
🧭 2차적 사고 (막스 / 클라만)

1차적 사고: [시장이 지금 믿고 있는 것 한 줄]
2차적 사고: [그래서 무엇이 이미 가격에 있고, 무엇이 안 들어있나]

사이클 위치: [진자 어디쯤 + 근거]
영구 손실 시나리오: [무엇이 깨지면 회복 불가인가]
```

### 💬 5. 투자 격언

상황에 가장 적합한 격언을 선별해 제공한다.
- 기본 3~5개. **호출한 스킬이 개수를 지정하면 그 개수를 따른다** (예: `summarize-telegram` 은 2~3개).
- 단순 나열이 아닌, 현재 맥락에 왜 이 격언이 적합한지 한 줄 해설을 붙인다.
- 출처(인물 또는 월가 속담)를 반드시 명시한다.
- **사용자 룰과 연결되는 격언을 우선 고른다** (`references/aphorisms.md` 의 「룰 ↔ 격언 매핑」 참조).

격언 목록은 `references/aphorisms.md` 를 참조하라.

**출력 형식:**
```
💬 지금 이 상황에 어울리는 격언

1. "[격언]" — [출처]
   → [이 상황에 적용되는 이유 한 줄]

2. ...
```

## 🛡️ 6. 룰 체크 (의사 결정 조언 시 필수)

매수/매도/보유/손절/비중 조언에는 **이 블록을 반드시 넣는다.** 대가 관점만 쓰고 끝내지 마라.
`context/my_rules.md`「적용 방법」이 요구하는 4가지를 그대로 채운다.

**출력 형식:**
```
🛡️ 룰 체크

- 진입가: [단일 가격]
- 「매매규칙 7」 -10% 비중 축소 고려선: [원화 환산]
- 「매매규칙 6」 -15% 1차 분할 매도선: [원화 환산] (시장 급락 예외 해당 여부)
- 「매매규칙 6」 -20% 전량 매도선: [원화 환산] — 이 선이 포지션의 최대 손실이다
- 「매매규칙 11」 24~30% 익절 구간: [원화 환산] — 보유량 10~30% 분할
- 「기본 원칙 4」 2%룰 포지션 상한 — 「매매규칙 9」의 두 축을 갈라 쓴다:
      매수원금 비중 상한 = 2% ÷ 실효 손절폭      → [계산 결과 %] · 진입 크기를 구속
      평가 비중 상한 35%                        → 진입 후 상승분에 걸리는 별개 선
      (실효 손절폭 하한은 20% — 「매매규칙 6」 최종 이탈선)
- 「기본 원칙 13」 계좌 MDD: [직전 고점 대비 현재 %] → [해당 없음 / -10% 발동 / -15% 발동 + 필요 조치]
- 「기술적 분석 규칙 1」 주봉 20주선: [방향 + 주가 위치] → [진입 가능 / 보류 / 밸류 예외 + 근거]
- 저촉 룰: [위반·근접한 룰 번호와 원문. 없으면 "없음"]
```

조건부 룰 — 해당하면 반드시 추가한다:
- 이벤트(상장·학회·출시·정책) 근거 매매면 「매매규칙 14」: 대장주 여부 + 이벤트 매매 누적 5% 한도 확인
- 서프라이즈 실적 직후면 「매매규칙 13」: 원인 규명 전 매수 금지
- 장대 양봉 구간이면 「매매규칙 12」: 그 위에 진입가 잡지 않는다
- 지수·섹터 레버리지 얘기면 「레버리지 규칙 3」: 최근 10거래일 ±5% 변동일 3일 이상인지
- 손실 중 추가 매수 고민이면 「매매규칙 8(물타기 금지)」을 **조언 서두에서** 먼저 상기시킨다

## 🎯 7. 종합 판단 (의사 결정 조언 시 필수)

관점을 나열하고 끝내지 마라. **하나의 결론과 확신도를 낸다.**

**출력 형식:**
```
🎯 종합 판단

판단: [매수 / 분할 매수 / 관망 / 비중 축소 / 회피]
확신도: [상 / 중 / 하]
근거: [한 줄]
관점 충돌: [충돌한 관점과, 어느 쪽을 왜 택했는지. 충돌 없으면 "없음"]
판단을 뒤집는 조건: [구체적 사건 또는 수치]
```

**확신도 기준**

| 등급 | 조건 |
|---|---|
| 상 | 네 관점 중 3개 이상 합치 + 데이터 결손 없음 + 룰 저촉 없음 |
| 중 | 관점 2개 합치, 또는 데이터 1개 결손, 또는 룰 근접 |
| 하 | 관점이 갈림, 또는 데이터 2개 이상 결손, 또는 룰 저촉 존재 |

`analyze-stock` 에서 호출된 경우: **출발점은 9단계 기대수익 판정이다.** 관점이 그것을 뒤집으면
뒤집는 근거를 명시한다. 근거 없이 다른 결론을 내지 않는다.

## 대가 기준 vs 사용자 룰 충돌 처리

가장 자주 부딪히는 지점이다. **매번 재논쟁하지 말고 아래대로 처리한다.**

| 항목 | 대가 기준 | 사용자 룰 | 처리 |
|---|---|---|---|
| 손절폭 | 오닐 -7~8%, 미너비니 -5~8% | 「매매규칙 6」 **-15% 1차 분할 → -20% 전량** | **사용자 룰 우선.** 포지션의 최대 손실은 최종 이탈선인 -20%다. 손절폭이 2~3배 넓은 대신 「기본 원칙 4」 2%룰이 매수원금 비중을 **10%**(= 2% ÷ 20%)로 조인다. 리스크 총량은 같다 — 대가 대비 "느슨한" 게 아니라 **사이징으로 상쇄**하는 구조다 |
| 기대수익 | 오닐 20~25% 익절 | 「기본 원칙 2」 6~12개월 **50~100%** | 사용자 룰 우선. 단 「매매규칙 11」로 24~30%에서 10~30% 쿠션 확보 — 오닐 익절과 부분적으로 만난다 |
| 물타기 | 오닐: 절대 금지 | 「매매규칙 8」: 절대 금지 | 일치. 가치투자 관점이 "싸졌으니 더 사라"고 하면 **룰이 이긴다** |
| 집중 투자 | 멍거·드루켄밀러: 크게 베팅 | 「기본 원칙 10」 강한 베팅 + 「기본 원칙 4」 2%룰 | 확신은 크게, **크기는 2%룰 안에서.** 확신을 이유로 상한을 넘지 않는다 |
| 매도 타이밍 | 미너비니: 추세 이탈 즉시 | 「매매규칙 3」 추세 꺾이기 전 섣불리 안 팜 | 방향 같음. 「매매규칙 5」에 따라 분할. 단 아이디어 훼손·「레버리지 규칙 3」 발동 시는 즉시 전량 |
| 손절 예외 | 없음 | 「매매규칙 6」 시장 급락 시 예외 | 예외 적용하려면 **지수 낙폭 수치를 근거로** 대야 한다. "시장이 안 좋아서"는 근거가 아니다 |

원칙: **룰이 이긴다. 단, 룰이 왜 그렇게 생겼는지 설명하고 넘어간다.**

## 중요한 원칙

- **모르면 모른다고 하라.** 종목 데이터가 없거나 불충분하면 추측하지 말고 어떤 정보가 더 필요한지 안내하라.
- **대가들의 관점은 상충할 수 있다.** 가치투자자가 "보유"를 외칠 때 추세 추종자는 "손절"을 외칠 수 있다.
  이 긴장 관계를 솔직하게 제시하라. 억지로 합의시키지 말 것. 단 §7에서는 반드시 한쪽을 택한다.
- **숫자는 근거가 있을 때만 사용하라.** 실제 수치 없이 "PER이 낮다"고 쓰지 말 것.
  사용자가 제공했거나, 「데이터 조달」 경로로 확인한 경우에만 인용하라.
- **가격은 실행값이다.** 진입가·손절가·익절선은 **단일 가격**으로 낸다. 범위는 목표주가·기대수익에만 쓴다.
- **평단에 앵커링하지 마라.** 「기본 원칙 6」대로 "지금 현금 100%라면 이 포지션을 잡겠는가"로 되묻는다.
  단 룰 체크(§6)는 실제 보유 수량·평단 기준으로 계산한다 — 원점 사고는 판단에, 실제 수치는 실행에 쓴다.

## 출력 품질 기준

- 본문은 **caveman full**. 불릿이 기본 단위, 조사·군더더기 제거, 문장 파편 허용.
- 관점당 불릿 2~4개. 3줄 넘는 산문 금지.
- 나열 3개 이상 + 비교 축이 있으면 표로.
- 인과는 화살표로: `금리 인하 → 유동성 유입 → 성장주 멀티플 확장`
- 「🛡️ 룰 체크」와 「🎯 종합 판단」은 **오독 위험이 크므로 완전한 문장으로** 쓴다.
