# Quick Brief — 보유·관심 종목 간이 브리핑

세션 안에서 읽고 끝나는 브리핑이다. **파일을 만들지 않고, StockEasy에 접근하지 않는다.** 이미 등록된
매매 트리거를 현재가와 대조해 보여 주기만 하고, 감시 파일은 고치지 않는다 — 가격선 등록·갱신과 기록은
`daily-digest` 1-3-2·1-3-3단계의 몫이다. 수집 경로의 세부는 `market-data`가 정본이다 — 여기서 다시 적지 않는다.

## 1. 시세·뉴스 수집

```bash
uv run python .agents/skills/quick-brief/scripts/brief_prep.py [--days 2] [--json]
```

- 보유 = 최신 포트폴리오 스냅샷(`output/portfolio/`), 관심 = `context/interested_stocks.md`. 보유가 먼저다.
- 현재가·등락률 = 네이버(장중이면 장중가, 마감 뒤면 그날 가격 — 참고값), 공식 종가 = 금융위 직전 정규장 종가.
- 뉴스 = 네이버 종목 뉴스, `--days` 이내만, 종목당 최대 5건.
- 기준일·뉴스 기간은 KST 날짜다. `session`은 `intraday`(평일 09:00~15:40 KST) 또는 `closed`.
- 스냅샷의 「룰 자동 판정」(평단 축 매매규칙 6·7·9·11, 현금 비중) 줄을 그대로 싣는다 — 시트 수집 시점 값이다.
- 종료 코드 `0` 정상·부분 수집 · `1` 현재가를 하나도 못 받음. 「미수집」 절의 사유는 그대로 옮긴다 —
  다른 출처 숫자로 메우지 않는다.
- 호스트별 요청 간격 때문에 20여 종목에 2~3분 걸린다. 백그라운드로 돌리고 2단계를 함께 진행한다.

**금지:** `fetch_stock_info.py`·`stage_scan.py`·`turn_scan.py`·`canslim_scan.py`·`fetch_market_signals.py`·
`fetch.py quote`처럼 StockEasy를 타는 스크립트는 부르지 않는다.

## 2. OpenDART 공시

`opendart` 스킬의 MCP 도구로 본다.

1. `risk_events`를 `company` 공백으로 1회 — 시장 전체 최근 30일 횡령·배임·중대재해 중 보유·관심 종목만 남긴다.
2. 종목마다 `company`(query = 종목명, `start_date` = 오늘 - `--days`, `max_recent_filings` 소량)로 최근 공시
   인덱스를 본다. ETF는 건너뛴다. 우선주는 본주로 조회한다. 유의사항의 「최근 공시 인덱스 조회 실패: 013」은
   DART의 「조회된 데이터 없음」 — 기간 내 공시 없음으로 읽는다(2026-10-20 대덕전자 실측).
3. 특이 공시만 추린다: 단일판매·공급계약, 유상증자·CB·BW, 최대주주·5% 변동, 잠정실적, 자사주 취득·처분,
   합병·분할, 거래정지·관리종목. 정기 보고서·임원 소유 소량 변동은 뺀다.

## 3. 트리거 대조

`output/watchlist/보유_트리거.md`(보유 종목별 절·「선매집 대기」·「추세 전용 대기」·지수 ETF 절)와
`output/watchlist/돌파선_감시.md`(「감시 대상」 표)를 읽는다. 종목마다 **현재 유효한 선**만 쓴다 — 가장 최근 날짜의
사용자 결정·점검 줄이 대체한 옛 선은 버린다(「매매규칙 18」 전환 뒤 옛 선은 소급 집행하지 않는다).

| 결과 | 조건 |
|---|---|
| 🔴 매도선 이탈 | 현재가 < 하한·매도선·마지노선 |
| 🟢 매수 조건 가격 충족 | 현재가가 매수 창·돌파선 조건 안 (가격 외 조건 — 단계·수급·날짜 — 은 미확인으로 적는다) |
| ⛔ 계획 무효 | 현재가 < 무효화선·재금지선 |
| ⚠️ 근접 | 선까지 ±3% 이내 |

- `session`이 `intraday`면 모든 결과에 **「장중·미확정」**을 붙인다. 판정은 종가로만 한다.
- `closed`면 금융위 공식 종가 날짜가 오늘이면 그것을, 아니면 네이버 마감가를 쓰고 「네이버 종가, 공식 확인 전」으로 적는다
  (네이버 마감가에는 시간외가가 섞일 수 있다).
- 매도선 이탈 종목은 「매매규칙 18」(보류는 다음 거래일 종가까지 1회)을 한 줄로 덧붙인다. 집행 수량은 감시 파일에 적힌
  그대로 옮긴다 — 다시 계산하지 않는다.
- 해당 없음·근접 아님 종목은 적지 않는다.

## 4. 뉴스 선별

- 1단계 제목 중 **종목 고유 사건**(수주·실적·소송·규제·신제품·지분)만 남긴다. 시황·지수 기사, 다른 종목이 주인공인
  기사, ETF 출시 기사는 버린다.
- 제목만으로 내용을 알 수 없는 사건만 WebSearch로 1회 보충한다. 시세 숫자는 WebSearch로 바꾸지 않는다.

## 5. 브리핑 (세션 출력만)

최대한 짧게. 표와 불릿을 쓴다. 특이사항 없는 종목은 적지 않는다.

```markdown
**YYYY-MM-DD HH:MM KST · 장중/마감 · 스냅샷 MM-DD**

| 종목 | 현재가 | 등락 | 평단 대비 | 비중 |
|---|---:|---:|---:|---:|
(보유 전부)

| 관심 | 현재가 | 등락 |
|---|---:|---:|
(관심 전부, 한 표)

**트리거** (장중·미확정 / 종가)
- 🔴 종목 현재가 < 선(이름) — 수량 · 「매매규칙 18」
- ⚠️ 종목 현재가 · 선까지 -x.x%

**룰 자동 판정** (스냅샷 MM-DD, 해당 있는 줄만)

**특이사항**
- 종목: 한 줄 요약 · 출처(언론사 또는 DART 공시명)

**한 줄:** 오늘 포트 전체 흐름과 트리거 요약 한 문장
```

- 등락 ±5% 이상은 굵게 표시한다.
- 머리줄 「장중/마감」은 스크립트 `session`을 그대로 쓴다.
- 미수집 종목은 표에 `미수집`으로 남기고 표 아래 한 줄로 사유를 적는다.
