# Quick Brief — 보유·관심 종목 간이 브리핑

세션 안에서 읽고 끝나는 브리핑이다. **파일을 만들지 않고, StockEasy는 3단계의 `turn_scan` 몇 건에만 쓴다.** 이미 등록된
매매 트리거를 현재가와 대조해 보여 주기만 하고, 감시 파일은 고치지 않는다 — 가격선 등록·갱신과 기록은
`daily-digest` 1-3-2·1-3-3단계의 몫이다. 수집 경로의 세부는 `market-data`가 정본이다 — 여기서 다시 적지 않는다.

## 1. 시세·뉴스 수집

```bash
uv run python .agents/skills/quick-brief/scripts/brief_prep.py [--days 2] [--json]
```

- 보유 = 최신 포트폴리오 스냅샷(`output/portfolio/`), 관심 = `context/interested_stocks.md`, 트리거 =
  `output/watchlist/보유_트리거.md`·`매수_트리거.md`의 `## 종목명 (티커)` 절과 「감시 대상」 표 종목. 순서는 보유(스냅샷 순서) →
  관심·트리거 전용(등락률 내림차순, 현재가 미수집은 끝)이고, 트리거 종목은 적힌 티커로 바로 받는다. 3단계 트리거 점검 범위가 이 트리거 종목 전체다(관심 목록이 아니다).
- 현재가·등락률 = 네이버(장중이면 장중가, 마감 뒤면 그날 가격 — 참고값), 공식 종가 = 금융위 직전 정규장 종가.
- 뉴스 = 네이버 종목 뉴스, `--days` 이내만, 종목당 최대 5건.
- 기준일·뉴스 기간은 KST 날짜다. `session`은 `intraday`(평일 09:00~15:40 KST) 또는 `closed`.
- 시장 = KOSPI·KOSDAQ 네이버 지수 일봉 + 현재가. 오늘 값을 현재가로 덮어 3·20·200일선 위/아래, 20일선 전환,
  52주 고점 대비 낙폭과 「시장 국면」(정상·조정·약세·급락),
  「매매 규칙 3」 필터(200일선 위), 「레버리지 규칙 3」을 낸다. 임계값은 `daily-digest`의 `fetch_market_signals.py`와
  같다. **클라이맥스는 내지 않는다** — 반대매매가 StockEasy에만 있고 하루 늦게 나온다. 지수 수집 실패도 비블로킹이다.
- 스냅샷의 「룰 자동 판정」(평단 축 매매 규칙 6·9·10, 현금 비중) 줄을 그대로 싣는다 — 시트 수집 시점 값이다.
- 종료 코드 `0` 정상·부분 수집 · `1` 현재가를 하나도 못 받음. 「미수집」 절의 사유는 그대로 옮긴다 —
  다른 출처 숫자로 메우지 않는다.
- 호스트별 요청 간격 때문에 20여 종목에 2~3분 걸린다. 백그라운드로 돌리고 2단계를 함께 진행한다.

**금지:** `fetch_stock_info.py`·`stage_scan.py`·`canslim_scan.py`·`fetch_market_signals.py`·
`fetch.py quote`처럼 StockEasy를 타는 스크립트는 부르지 않는다. 예외는 3단계의 `turn_scan`뿐이다.

## 2. OpenDART 공시

`opendart` 스킬의 MCP 도구로 본다.

1. `risk_events`를 `company` 공백으로 1회 — 시장 전체 최근 30일 횡령·배임·중대재해 중 1단계 수집 종목만 남긴다.
2. 종목마다 `company`(query = 종목명, `start_date` = 오늘 - `--days`, `max_recent_filings` 소량)로 최근 공시
   인덱스를 본다. ETF는 건너뛴다. 우선주는 본주로 조회한다. 유의사항의 「최근 공시 인덱스 조회 실패: 013」은
   DART의 「조회된 데이터 없음」 — 기간 내 공시 없음으로 읽는다(2026-10-20 대덕전자 실측).
3. 특이 공시만 추린다: 단일판매·공급계약, 유상증자·CB·BW, 최대주주·5% 변동, 잠정실적, 자사주 취득·처분,
   합병·분할, 거래정지·관리종목. 정기 보고서·임원 소유 소량 변동은 뺀다.

## 3. 트리거 대조

`output/watchlist/보유_트리거.md`(보유 종목별 절·「선매집 대기」·「추세 전용 대기」·지수 ETF 절)와
`output/watchlist/매수_트리거.md`(「감시 대상」 표와 `## 종목명 (티커)` 절 — 미보유 매수 후보)를 읽는다. 종목마다 **현재 유효한 선**만 쓴다 — 가장 최근 날짜의
사용자 결정·점검 줄이 대체한 옛 선은 버린다(「매매 규칙 7」 전환 뒤 옛 선은 소급 집행하지 않는다).

| 결과 | 조건 |
|---|---|
| 🔴 매도선 이탈 | 현재가 < 하한·매도선·마지노선 |
| 🟢 매수 조건 가격 충족 | 현재가가 항목에 적힌 매수 조건(돌파선·눌림 창·가격 상한) 안 (가격 외 조건 — 단계·수급·날짜 — 은 미확인으로 적는다) |
| 🟢 국면 조건 충족 | 항목의 매수 조건이 「<지수> 시장 국면 급락·클라이맥스일 종가」이고, 1단계 시장 블록에서 그 지수(KOSPI·KOSDAQ)가 급락 |
| 🟢 하락일 | 항목의 매수 조건이 「하락할 때만 매수」(재량 분할)이고, 그 종목 오늘 등락률이 마이너스 |
| ⛔ 계획 무효 | 현재가 < 무효화선·재금지선 |
| ⚠️ 근접 | 선까지 ±3% 이내 |

- **국면 조건 항목은 지수 판정으로 채점한다** (2026-11-22 사용자 결정 — 급락일 바텀피싱 1차 묶음은 장 마감 동시호가 전에 알아야 집행된다).
  그 지수가 급락이면 `🟢 국면 조건 충족 — <종목> 1차 <수량>주(<지수> 급락)`로 트리거 절 **맨 위**에 올리고, 같은 날 충족 종목의
  합계 금액(현재가 × 수량)을 한 줄 붙인다. 클라이맥스는 이 스킬이 판정하지 못하므로 「클라이맥스 미판정」을 함께 적는다.
  지수가 급락이 아니면 `⏳ 국면 대기 — <지수> <국면명>`으로 한 줄씩 적는다. 하락일 항목은 `🟢 하락일 — 재량 매수 가능 (<등락률>)`이고, 집행 지시가 아니다.

- `session`이 `intraday`면 모든 결과에 **「장중·미확정」**을 붙인다. 판정은 종가로만 한다.
- `closed`면 금융위 공식 종가 날짜가 오늘이면 그것을, 아니면 네이버 마감가를 쓰고 「네이버 종가, 공식 확인 전」으로 적는다
  (네이버 마감가에는 시간외가가 섞일 수 있다).
- 매도선 이탈 종목은 「매매 규칙 7」(보류는 다음 거래일 종가까지 1회)을 한 줄로 덧붙인다. 집행 수량은 감시 파일에 적힌
  그대로 옮긴다 — 다시 계산하지 않는다.
- 해당 없음·근접 아님 종목은 적지 않는다.
- **보유 종목 매수 tranche는 「고개 들기」까지 채점한다.** `보유_트리거.md`의 보유 종목 매수 조건에 「고개 들기」(`turn_scan`)가
  있고 가격 조건이 🟢 또는 ⚠️ 근접이면 그 종목만 순차로 돌린다(사용자 허용 2026-11-16 — StockEasy 몇 건은 괜찮다):
  ```bash
  uv run python .agents/skills/stage-analysis/scripts/turn_scan.py <티커>
  ```
  판정이 「고개 들기」이고 가격 조건도 충족이면 `🟢 매수 조건 충족 — <tranche> <수량>주`로 트리거 절 **맨 위**에 올리고
  남은 미확인 조건(예: 「매매 규칙 11」 장중 고가)만 덧붙인다. 「고개 들기」가 아니면 그 판정명을 적는다. 장중이면
  `turn_scan`의 오늘 봉도 미확정이라 「장중·미확정」을 붙인다. 실패하면 「고개 들기 미확인 (turn_scan 실패 — 사유)」로 적는다.
  미보유 후보(`매수_트리거.md`)는 이 대상이 아니다 — 지금처럼 「가격만 충족」으로 적는다.
  2026-11-16 삼양식품 B2가 가격은 충족했는데 고개 들기 미확인으로만 나가 충족 확정이 저녁 `daily-digest`까지 늦었다.

## 4. 뉴스 선별

- 1단계 제목 중 **종목 고유 사건**(수주·실적·소송·규제·신제품·지분)만 남긴다. 시황·지수 기사, 다른 종목이 주인공인
  기사, ETF 출시 기사는 버린다.
- 제목만으로 내용을 알 수 없는 사건만 WebSearch로 1회 보충한다. 시세 숫자는 WebSearch로 바꾸지 않는다.

## 5. 브리핑 (세션 출력만)

출력 양식의 정본은 `template/quick_brief.md`다. 이 파일을 읽고 절 순서·제목·표 열을 그대로 채운다.

- 실행 시점은 장중 또는 장 마감 직후다. 오늘 값이 들어간 판정(시장 표·트리거)에는 `session`에 맞춰
  「장중·미확정」 또는 「네이버 종가」 꼬리표를 붙인다.
- 내용 없는 절은 지우지 않고 「— 없음」 한 줄로 남긴다.
- 보유 표는 비중 내림차순, 관심 표는 등락률 내림차순(스크립트 출력 순서)으로 등락 ±3% 이상·트리거 해당·공시·뉴스 있음 중 하나라도 해당하는 종목만 싣는다.
- 시장 블록의 판정은 스크립트 출력을 그대로 옮기고 재채점하지 않는다.
