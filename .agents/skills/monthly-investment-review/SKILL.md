# 월간 투자 반성

노션 투자일지 → 반성/실수 추출 → 대가 관점 조언 → 노션 상단 기록.

## 동작 모드

설치된 `caveman` 스킬을 `full` 강도로 활성화한다. 대화와 노션 분석에 같은 강도를 적용한다.
짧고 명확한 불릿을 기본으로 쓰고, 사례·원인·개선 행동은 필요한 경우 하위 불릿으로 묶는다.

## 실행

### 1. 페이지 찾기

월/연도 지정 시(예: "3월", "2026/03") 해당 페이지 검색. 미지정 시 직전 월.

1. 사용 가능한 노션 검색 기능 → 쿼리: `"{연도}/{월} 투자"`
2. 투자일지 DB 하위 페이지 선택
3. 사용 가능한 노션 페이지 조회 기능으로 내용 가져오기
4. 큰 페이지가 파일로 반환되면 로컬 파일 도구로 본문을 나누어 읽기
5. 직전 월 페이지도 같은 방법으로 읽어 반복 실수를 비교한다. 없거나 조회 실패하면
   비교 불가 사유를 남긴다. `context/my_rules.md`를 읽고 원문 번호에 맞춰 복기한다.

Claude Code에서는 설치된 Notion 플러그인을 사용하고, Codex에서는 설치된
Notion 플러그인/앱 커넥터를 사용한다. 필요한 읽기 또는 쓰기 기능이 없으면
대체 데이터를 추측하지 말고 연결 또는 권한 누락을 보고한다.

### 2. 반성 추출

키워드 중심 분석: 반성, 개선, 실수, 분할매도, 감정, 손절, MDD, 희망회로

추출 요소:
- 월간 수익률, MDD
- 종목별 매매 복기 (진입/매도 사유, 손익, 반성)
- 반복 실수 패턴
- 포트폴리오 이슈
- 개선 사항
- 후회, 반성 항목

### 3. advice 관점 적용

`../advice/references/` 참조:
- `value_investing.md` — 버핏, 멍거, 린치
- `trend_following.md` — 미너비니, 오닐
- `macro.md` — 드루켄밀러, 소로스
- `second_level_thinking.md` — 하워드 막스, 세스 클라만 (2차적 사고·사이클·영구 손실)
- `aphorisms.md` — 격언

원칙:
- 반성 항목당 적합한 1~2명만
- 대가 철학 기반 코멘트 (단순 인용 X)
- 상충 관점 솔직 제시

### 4. 노션 기록

기존 페이지 본문과 이번 분석을 각각 로컬 파일로 준비하고, 아래 스크립트로 월별 리뷰 블록을 갱신한다.
이번 분석은 `output/reviews/<yyyy>/<mm>/<yyyy-mm>_monthly.md`(리뷰 대상 월 기준)에, 갱신 본문은 같은
폴더의 `<yyyy-mm>_monthly_merged.md`에 둔다. 주간 리뷰와 같은 `<yyyy>/<mm>/` 폴더라 한 달의 리뷰가
한 곳에 모인다.

```bash
uv run python .agents/skills/monthly-investment-review/scripts/review_upsert.py \
  --existing <기존 본문.md> \
  --proposed output/reviews/2026/09/2026-09_monthly.md --month 2026-09 \
  --prepared-out output/reviews/2026/09/2026-09_monthly_merged.md --json
```

스크립트가 만든 월별 고유 표식은 노션 저장 시에도 보존한다. 같은 월 재실행은 해당 블록만
교체하며 일지 본문은 유지한다. 저장 직전 페이지를 다시 읽어 기존 본문이 바뀌지 않았는지
확인한 뒤, 연결 도구로 해당 블록을 반영한다. 저장 후 다시 읽어 리뷰가 1개인지 확인한다.
연결 도구가 표식을 보존하지 못하면 반환된 블록 ID를 기록해 같은 블록을 갱신한다.

## 출력 형식

`caveman full`로 핵심 사례와 개선 행동을 쓴다. 문장은 짧고 명확하게 유지한다.

```markdown
## {월} 투자 반성

[총평]
[핵심 개선 사항 한 줄 요약]

**1. [제목]**
- [사례 1~2줄]
- [개선 방향]

**2. [제목]**
- [사례]
- [개선 방향]

### 개선 방향
| # | 항목 | 개선 방향 |
|---|------|------|
| 1 | ... | ... |


---
```

## 주의

- 같은 반성 반복 등장 → 빈도가 심각성 지표 → 강조
- 이전 월과 비교해 같은 실수 반복 여부 확인
- 검색 결과가 여러 개면 쓰기 전에 대상 페이지를 확인하고 변경 미리보기를 제시
