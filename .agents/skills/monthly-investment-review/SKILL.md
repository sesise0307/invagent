# 월간 투자 반성

노션 투자일지 → 반성/실수 추출 → 대가 관점 조언 → 노션 상단 기록.

## 동작 모드

설치된 `caveman` 스킬을 `full` 강도로 활성화한다. 사용자 응답과 노션
출력물 모두 같은 간결한 스타일을 적용한다.

## 실행

### 1. 페이지 찾기

월/연도 지정 시(예: "3월", "2026/03") 해당 페이지 검색. 미지정 시 직전 월.

1. 사용 가능한 노션 검색 기능 → 쿼리: `"{연도}/{월} 투자"`
2. 투자일지 DB 하위 페이지 선택
3. 사용 가능한 노션 페이지 조회 기능으로 내용 가져오기
4. 큰 페이지가 파일로 반환되면 로컬 파일 도구로 본문을 나누어 읽기

Claude Code에서는 설치된 Notion 플러그인을 사용하고, Codex에서는 설치된
Notion 플러그인/앱 커넥터를 사용한다. 필요한 읽기 또는 쓰기 기능이 없으면
대체 데이터를 추측하지 말고 연결 또는 권한 누락을 보고한다.

### 2. 반성 추출

키워드 중심 분석: 반성, 개선, 실수, 분할매도, 감정, 손절, MDD, 희망회로

추출 요소:
- 월간 수익률, MDD
- 종목별 매매 복기 (진입/매도 사유, 손익, 반성)
- 반복 실수 패턴
- 포트폴리오 이슈
- 개선 사항
- 후회, 반성 항목

### 3. advice 관점 적용

`../advice/references/` 참조:
- `value_investing.md` — 버핏, 멍거, 린치
- `trend_following.md` — 미너비니, 오닐
- `macro.md` — 드루켄밀러, 소로스
- `second_level_thinking.md` — 하워드 막스, 세스 클라만 (2차적 사고·사이클·영구 손실)
- `aphorisms.md` — 격언

원칙:
- 반성 항목당 적합한 1~2명만
- 대가 철학 기반 코멘트 (단순 인용 X)
- 상충 관점 솔직 제시

### 4. 노션 기록

사용 가능한 노션 페이지 갱신 기능으로 기존 본문 일부를 교체한다.
기존 첫 `##` 헤딩 앞에 삽입:
- `old_str`: 첫 `##` 헤딩
- `new_str`: 분석 + 기존 헤딩

## 출력 형식

caveman 스타일. 핵심만. 군더더기 없이.

```markdown
## {월} 투자 반성

[총평]
[핵심 개선 사항 한 줄 요약]

**1. [제목]**
- [사례 1~2줄]
- [개선 방향]

**2. [제목]**
- [사례]
- [개선 방향]

### 개선 방향
| # | 항목 | 개선 방향 |
|---|------|------|
| 1 | ... | ... |


---
```

## 주의

- 같은 반성 반복 등장 → 빈도가 심각성 지표 → 강조
- 이전 월과 비교해 같은 실수 반복 여부 확인
- 검색 결과가 여러 개면 쓰기 전에 대상 페이지를 확인하고 변경 미리보기를 제시
- "AI 작성", "참고용", "최종 판단은 본인" 등 면책 문구 금지
