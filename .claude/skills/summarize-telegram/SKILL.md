# 텔레그램 데일리 브리핑 스킬

텔레그램 '저장한 메시지'의 raw 데이터를 읽고, 섹터/종목별로 분류 후 핵심 인사이트를 추출한다.
`advice` 스킬의 세 가지 관점(가치투자/차트/매크로)을 통합해 투자 조언까지 포함한 일일 브리핑을 생성한다.

## 기본 동작 모드

이 스킬은 **caveman 모드(full)**를 기본으로 사용한다. 스킬 실행 시 가장 먼저 `/caveman full` 스킬을 호출하여 caveman 모드를 활성화한 뒤 작업을 진행한다.

## 실행 순서

### 1단계: 데이터 준비

오늘 날짜를 `YYYY-MM-DD` 형식으로 확인한 뒤, 아래 파일이 존재하는지 확인한다:
```
output/telegram-daily/raw/<today>_raw.md
```

- **파일이 없으면**: 아래 명령어로 먼저 메시지를 가져온다
  ```bash
  cd /Users/sesise/1_Investment/invagent && uv run invagent fetch-messages --days 1
  ```
- **파일이 있으면**: 그대로 사용한다

`--days` 인자를 사용자가 지정했다면 해당 값을 사용하되, 파일명 날짜는 오늘 날짜 기준이다.

### 1-1단계: 시장 신호 수집 (StockEasy)

StockEasy 시장 분석 페이지에서 시장 신호를 수집한다:

```bash
cd /Users/sesise/1_Investment/invagent && python3 .claude/skills/summarize-telegram/scripts/fetch_market_signals.py
```

출력 내용 (신호등, 오닐 빅픽처, 지수, breadth, 신용/수급)을 해석해 브리핑 템플릿 최상단
「🚦 시장 상황」 섹션에 정리한다. 단순 수치 나열이 아니라 **한줄 판단**(현재 국면 + 대응 스탠스)까지 도출한다.

- **실패 시 (exit 1)**: 브리핑 시장 상황 섹션에 "(시장 신호 수집 실패)" 한 줄만 표기하고
  나머지 단계는 정상 진행한다. 이 단계 실패가 브리핑 생성을 블로킹해서는 안 된다.

### 1-2단계: 변동성 지수 수집 (VKOSPI)

코스피 변동성 지수(VKOSPI, 코스피200 변동성지수 = 한국판 VIX)를 investing.com에서 가져온다.

**WebFetch 툴을 사용한다** (curl/스크립트는 Cloudflare 403으로 차단됨):

```
WebFetch(
  url="https://www.investing.com/indices/kospi-volatility",
  prompt="Extract the current KOSPI Volatility Index value, change, percent change,
          day's range, previous close, 52-week range, and last update time."
)
```

추출 항목: **현재가 · 전일대비(%) · 전일종가 · 일간범위 · 52주 범위 · 갱신시각**.

**해석 기준**:
- 절대 레벨 밴드 (평시): ~20 이하 안일 / 20~30 정상 / 30~40 경계 / 40 이상 공포
- **단, 절대 밴드만 쓰지 말 것.** 2026년 한국 증시는 VKOSPI 70~95 구간의 이상 국면이라
  절대 밴드가 무의미해질 수 있다. **52주 범위 내 위치**(`(현재-52주저)/(52주고-52주저)`)와
  **전일대비 방향**을 함께 판단 근거로 쓴다.
- 변동성 **급등**(전일比 +10% 이상) = 리스크 오프 가속 → 신규 진입 보류·포지션 축소 신호
- 변동성 **고점권에서 하락 전환** = 패닉 피크아웃 가능성 → 분할 매수 관찰 구간
- 지수는 오르는데 VKOSPI도 높음 = 양방향 급등락 국면 → 방향성 베팅보다 포지션 사이징 관리

**참고**: investing.com 값은 KRX 공식 VKOSPI와 스케일·수준이 일치하나 52주 고점 등 일부
수치는 미세 차이가 있을 수 있다. 사상 최고치 등 기록 수치를 인용할 때는 KRX 공식 기준을 쓴다.

- **실패 시**: 시장 상황 섹션에 "(VKOSPI 수집 실패)" 한 줄만 표기하고 나머지 단계는 정상 진행한다.
  이 단계 실패가 브리핑 생성을 블로킹해서는 안 된다.

### 2단계: 메시지 분류 및 인사이트 추출

**raw 파일 읽기 방법 (대용량 파일 대응)**

raw 파일은 수천 줄에 달할 수 있으므로 한 번에 읽지 말고 청크 단위로 나눠 읽는다:

```
Read(file_path, offset=0,   limit=200)   # 1번째 청크
Read(file_path, offset=200, limit=200)   # 2번째 청크
...반복...
```

- `limit`은 200줄 이하로 유지한다 (토큰 초과 오류 방지)
- 각 청크를 읽을 때마다 분류에 해당하는 내용을 즉시 메모해두고, 다음 청크로 넘어간다
- 파일 끝은 청크가 비어있거나 오류가 날 때 확인된다
- 모든 청크를 읽은 후 메모한 내용을 종합해 섹터/종목별로 정리한다

raw 파일 전체를 읽은 뒤 다음 기준으로 분류한다:

**분류 우선순위:**
1. **종목 언급**: 종목 이름이 직접 언급된 메시지
2. **섹터 관련**: 특정 섹터(반도체, 바이오, 소비재 등)에 해당하는 리포트/뉴스
3. **사용자 작성 메모**: 메모, 반성, 시황, 개인 의견 등
4. **매크로/시장 전반**: 금리, 환율, 지정학, 미국 증시 등 시장 전반 이슈

**각 종목/섹터에 대해 추출할 내용:**
- 핵심 인사이트: 투자 판단에 직결되는 내용 (증권사, 목표주가 변경, 실적 전망, 업황 변화 등)
- 원문 요약: 포워드/뉴스/리포트 내용을 1-3문장으로 압축
- 투자 시사점: 투자 의사 결정에 도움이 되는 핵심 인사이트 및 조언

**판단 기준:**
- 실적/매출 데이터 ATH(역대 최고)는 강한 모멘텀 신호로 적극 반영
- 증권사 리포트의 목표주가 상향/하향은 컨센서스 변화로 별도 표기
- 내부자 매수는 신뢰도 높은 신호로 강조
- 링크 읽기 타임아웃된 항목은 제목/맥락만으로 판단하고 "(링크 미확인)" 표기

### 2-1단계: 오늘의 헤드라인 TOP 1~2 선별

분류 끝낸 뒤 오늘 raw 데이터에서 **가장 임팩트 큰 1~2개**만 골라 헤드라인으로 별도 표시. 브리핑 맨 위에 들어간다.

**선별 기준 (우선순위)**:
1. 메가 이벤트: 정책 전환, 매크로 충격, 슈퍼사이클 신호
2. 컨센 점프: 다수 증권사 동시 목표가 상향/하향, 어닝 서프 큰 폭
3. 구조 변화: 신규 공급계약, 신시장 진입, 빅파마 딜, 표준 채택
4. 가격 액션: 거래량 동반 ATH 돌파, 섹터 동시 급등

**추출 형식**: 1줄 헤드라인 + 1줄 사실 근거 + 1줄 시사점. 단순 주가 변동만으로는 헤드라인 안 됨.

### 3단계: 월간 누적 컨텍스트 로드

매일 브리핑은 reset이지만 한 달 동안의 핵심 흐름은 별도 누적 파일에 보관한다:

```
output/telegram-daily/monthly_context.md
```

**조언/인사이트 작성 전 반드시 이 파일을 먼저 읽는다.** 구조 인식이 단일 일자보다 훨씬 강력하다.

이 파일이 담는 것:
- **반복 등장 신호**: 여러 날 걸쳐 같은 종목/섹터/매크로 이슈가 누적되는 패턴
- **메가 트렌드 트랙킹**: 진행 중인 슈퍼사이클·정책·지정학 흐름의 진척도
- **주요 이벤트 캘린더**: 학회·실적 발표·만기 이벤트 등 향후 트리거
- **컨센 변화 누적**: 한 종목/섹터에 대한 증권사 시각 변천

파일이 없으면 빈 상태로 시작. 너무 길어지면 30일 넘은 항목은 정리.

### 4단계: 투자 조언 생성

`advice` 스킬(`/Users/sesise/1_Investment/invagent/.claude/skills/advice/SKILL.md`)의 방법론을 참조한다.

**나만의 규칙 참조 (필수)**: 「의사 결정 조언」 섹션과 투자 조언 작성 시 advice 스킬의
「🛡️ 나만의 규칙」 섹션(-8% 분할매도·-15% 손절·2%룰·레버리지 룰·분할매도·24~30% 수익쿠션)을
반드시 참고하고, 조언이 규칙과 관련되면 해당 룰을 명시적으로 인용한다.

**🛡️ 오늘의 룰 리마인드 (브리핑 최상단, 필수)**: 브리핑 문서의 **가장 맨 위**
(제목 바로 아래, 「🚦 시장 상황」보다 먼저)에 나만의 규칙 중 **그 날의 시장 상황에 가장
적절한 항목 1~2개**를 채택해 리마인드 섹션으로 넣는다.

- 선택 기준 예시:
  - 지수 급락/급등·왕복 변동성 → 룰 6 (주간 ±5% 3일 이상 = 레버리지 전량 정리), 룰 5
  - 보유 종목 급락 언급 → 룰 1 (-8% 분할 매도·물타기 금지), 룰 2 (-15% 손절)
  - 급등주 추격 욕구·신규 진입 검토 → 룰 3 (2%룰 포지션 사이징)
  - 보유 종목 큰 수익 구간 → 룰 8 (24~30% 수익 시 1/3 익절), 룰 7 (분할 매도)
- 형식: 룰 원문 인용 + 오늘 상황에 왜 이 룰인지 1줄 연결. 3줄 이내로 짧게.

**원점 사고 원칙 (필수)**:
- **사용자 보유 종목 여부는 고려하지 않는다.** "내 포트에 있어서 좋다/없어서 안타깝다" 같은 관점 금지.
- **오늘 처음 시장을 보는 신규 투자자 관점**으로 작성한다. "지금 신규 진입할 만한가?", "지금 매도가 합리적인가?" 같은 zero-base 질문에 답한다.
- 보유 종목이 추천에서 누락돼도 문제 없음. 보유 종목이 부정적 신호 받아도 그대로 표기.
- 농구천재 인용 원칙: "오늘 현금 100이라면 이 비중이 맞나?"

오늘 메시지 + 월간 누적 컨텍스트에서 포착된 **가장 중요한 1-2개 테마**를 골라 세 관점에서 조언:

- **가치투자 관점**: 버핏/멍거/린치 시각으로 내재가치, 해자, 안전마진 관점
- **차트·추세 관점**: 미너비니/오닐 기준으로 스테이지, 진입/손절 조건
- **매크로 관점**: 드루켄밀러/소로스 시각으로 금리/유동성/자금 흐름

`references/` 디렉토리의 상세 방법론 파일도 참조할 수 있다:
- `advice/references/value_investing.md`
- `advice/references/trend_following.md`
- `advice/references/macro.md`
- `advice/references/aphorisms.md` — 상황에 맞는 격언 2-3개 선별

### 5단계: 브리핑 파일 저장

`template/telegram_daily.md` 템플릿 구조를 따라 브리핑을 작성하고 **월별 서브 디렉토리** 아래에 저장한다:

```
output/telegram-daily/<yyyy-mm>/<yyyy-mm-dd>.md
```

예: 오늘이 2026-05-08이면 → `output/telegram-daily/2026-05/2026-05-08.md`

월 디렉토리가 없으면 먼저 생성한다 (`mkdir -p`). 날짜는 오늘 날짜 (`_raw.md` 파일명과 동일한 날짜).

### 6단계: 월간 누적 컨텍스트 갱신

브리핑 저장 후 `monthly_context.md`를 갱신한다.

**갱신 룰**:
- 오늘 헤드라인 TOP 1~2 중 **반복성·구조성** 있는 것만 추가 (단발 이벤트는 스킵)
- 기존 항목 중 오늘 진척이 있으면 업데이트 (날짜 + 한 줄 추가)
- 이미 종료된 이벤트(실적 발표 끝, 학회 종료, 트렌드 소멸)는 제거
- 30일 경과 + 후속 신호 없는 항목 제거

**섹션 구조**:
```markdown
## 진행 중인 메가 트렌드
- {트렌드명} ({시작일~}): 한 줄 설명
  - YYYY-MM-DD: 진척 한 줄
  - YYYY-MM-DD: 진척 한 줄

## 반복 등장 신호
- {종목/섹터}: 누적 신호 요약 + 마지막 등장일

## 주요 이벤트 캘린더
- YYYY-MM-DD: {종목} {이벤트} (학회/실적/만기 등)

## 매크로 흐름
- {이슈}: 진행 상황 한 줄
```

파일을 저장한 뒤 저장 경로를 사용자에게 알린다.

### 7단계: 과거 raw 파일 정리

브리핑·월간 컨텍스트 저장이 모두 끝나면 오늘자 raw만 남기고 과거 raw 파일을 삭제한다. raw는 일회성 원본이라 누적할 이유 없음.

**선행 조건 (안전장치)** — 둘 다 충족해야 정리 진행. 하나라도 없으면 스킵 + 사유 알림:
- 오늘 브리핑 `output/telegram-daily/{yyyy-mm}/{today}.md` 존재 확인 (월별 서브 디렉토리 안)
- 오늘 raw `output/telegram-daily/raw/{today}_raw.md` 존재 확인

**삭제 명령**:
```bash
TODAY=$(date +%Y-%m-%d)
find /Users/sesise/1_Investment/invagent/output/telegram-daily/raw \
     -maxdepth 1 -type f -name '*_raw.md' \
     ! -name "${TODAY}_raw.md" -print -delete
```

- `-maxdepth 1`: 서브디렉토리 건드리지 않음
- `! -name "${TODAY}_raw.md"`: 오늘자 보존
- `-print -delete`: 삭제 경로 출력

**보존 대상 (절대 삭제 금지)**:
- `output/telegram-daily/raw/{today}_raw.md`
- `output/telegram-daily/{yyyy-mm}/{YYYY-MM-DD}.md` (월별 서브 디렉토리 안 브리핑 — raw 디렉토리 밖, 자동 보존)
- `output/telegram-daily/monthly_context.md` (자동 보존)

**사용자 보고**: 삭제된 파일 수, 보존된 오늘 raw 경로 출력.

## 출력 품질 기준

좋은 브리핑의 조건:
- **시장 상황 섹션**은 신호등 + 시장 상태(빅픽처) + **변동성(VKOSPI)** + 한줄 판단이 필수. 수치 나열로 끝내지 않는다
- **「📌 오늘의 시황 및 핵심 요약」 첫 불릿**은 오늘의 변동성 국면(VKOSPI 수준·방향)과 그에 따른
  대응 스탠스를 담는다. 수집 실패 시에만 생략
- **헤드라인 TOP 1~2**는 임팩트 큰 1~2개만. 단순 주가 변동 금지. 메가 이벤트·컨센 점프·구조 변화 위주
- **핵심 요약**은 오늘 가장 중요한 2-3가지 흐름을 담아야 한다 (단순 나열 X, 불릿 포인트 사용, 핵심만)
- **인사이트**는 "무슨 일이 있었다"가 아니라 "그게 왜 중요한가"에 답해야 한다 (불릿 포인트 사용, 핵심만)
- **투자 조언**은 오늘 메시지 + 월간 누적 컨텍스트의 구체적 내용을 근거로 해야 한다 (범용적 조언 X)
- **투자 조언은 원점 사고**: 사용자 보유 종목 여부 무관. 신규 진입자 관점으로 작성
- **액션 아이템**은 실제 후속 조치가 가능한 것만 넣는다

## 주의사항

- 링크 내용을 읽을 수 없었던 경우에도 메시지 제목/맥락으로 최대한 판단한다
- 수치(목표주가, 실적 등)는 원문에 명시된 것만 사용한다 — 추측 금지
- 사용자 포트폴리오·보유 여부를 추론하거나 반영하지 않는다. 시장 자체만 본다
