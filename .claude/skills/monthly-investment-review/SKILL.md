# 월간 투자 반성

노션 투자일지 → 반성/실수 추출 → 대가 관점 조언 → 노션 상단 기록.

## 동작 모드

**caveman full** 기본. 사용자 응답 + 노션 출력물 모두 caveman 적용.

## 실행

### 1. 페이지 찾기

월/연도 지정 시(예: "3월", "2026/03") 해당 페이지 검색. 미지정 시 직전 월.

1. `notion-search` → 쿼리: `"{연도}/{월} 투자"`
2. 투자일지 DB 하위 페이지 선택
3. `notion-fetch`로 내용 가져오기
4. 큰 페이지 → 파일 저장됨 → Bash로 JSON 파싱, text 추출

### 2. 반성 추출

키워드 중심 분석: 반성, 개선, 실수, 분할매도, 감정, 손절, MDD, 희망회로

추출 요소:
- 월간 수익률, MDD
- 종목별 매매 복기 (진입/매도 사유, 손익, 반성)
- 반복 실수 패턴
- 포트폴리오 이슈
- 개선 사항
- 후회, 반성 항목

### 3. advice 관점 적용

advice 스킬 `references/` 참조:
- `value_investing.md` — 버핏, 멍거, 린치
- `trend_following.md` — 미너비니, 오닐
- `macro.md` — 드루켄밀러, 소로스
- `aphorisms.md` — 격언

원칙:
- 반성 항목당 적합한 1~2명만
- 대가 철학 기반 코멘트 (단순 인용 X)
- 상충 관점 솔직 제시

### 4. 노션 기록

`notion-update-page` → `update_content` 명령.
기존 첫 `##` 헤딩 앞에 삽입:
- `old_str`: 첫 `##` 헤딩
- `new_str`: 분석 + 기존 헤딩

## 출력 형식

caveman 스타일. 핵심만. 군더더기 없이.

```markdown
## {월} 투자 반성

[총평]
[핵심 개선 사항 한 줄 요약]

**1. [제목]**
- [사례 1~2줄]
- [개선 방향]

**2. [제목]**
- [사례]
- [개선 방향]

### 개선 방향
| # | 항목 | 개선 방향 |
|---|------|------|
| 1 | ... | ... |


---
```

## 주의

- 같은 반성 반복 등장 → 빈도가 심각성 지표 → 강조
- 이전 월과 비교해 같은 실수 반복 여부 확인
- "AI 작성", "참고용", "최종 판단은 본인" 등 면책 문구 금지
