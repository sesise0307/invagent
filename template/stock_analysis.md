## 12. 개정 이력

> 승계 작성일 때만 채운다. 신규면 `신규 작성 — 개정 없음` 한 줄.
> 내 오판을 복기하기 위한 절이다. 본문을 현재 상태로 덮으므로 **과거의 나는 여기에만 남는다.**
> 형식: `- {yyyy-mm-dd}: {구분} — {요약 한 줄}` · 구분 = **정정 / 갱신 / 판단변경**
> 정정·판단변경은 근거(rcept_no · 리포트 파일명 · URL + 기준일)를 줄 안에 붙인다. 갱신은 선택.
> 오래된 줄은 지우지 않는다. 무제한 누적한다.

- {yyyy-mm-dd}: 판단변경 — [이전 판단] → [지금 판단]. [무엇이 바뀌어서] ([근거 + 기준일])
- {yyyy-mm-dd}: 정정 — [이전 서술] → [수정 서술]. [왜 틀렸나] ([rcept_no / 리포트 파일명 / URL + 기준일])
- {yyyy-mm-dd}: 갱신 — [새로 확인된 사실 + 수치] ([출처])

**이전 판단이 빗나간 지점**

- [당시 전제 → 실제 결과 → 왜 빗나갔나. 없으면 「빗나간 지점 없음」]
