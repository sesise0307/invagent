### 5-C. 종합 목표가

```
종합목표가 = w_c × 컨센평균목표가 + w_s × 시나리오확률가중가   (w_c + w_s = 1)
기대수익  = (종합목표가 - 현재가) / 현재가
손익비    = 기대수익 / 15%   (「매매규칙 6」 손절폭)
```
